# Proyecto: Librería Dover #
1. Inicio del proyecto

Comenzamos a realizar una página web para la Librería Dover, utilizando HTML5 y CSS3. Nuestro objetivo es crear una página sencilla, ordenada y adaptable a diferentes dispositivos.

2. Detalles del proyecto

En esta primera etapa realizamos lo siguiente:

- Creamos el archivo "index.html" para la estructura de la página.
- Agregamos el encabezado con el nombre y logotipo de Librería Dover.
- Creamos un menú de navegación básico.
- Añadimos una portada de bienvenida.
- Colocamos tres categorías: Escolar, Oficina y Papelería.
- Agregamos imágenes de los productos.
- Creamos el archivo CSS para colocar colores, tamaños y organizar las secciones.
- Utilizamos Media Queries para adaptar el diseño a celulares y computadoras.

3. Avance realizado:

Hasta el momento tenemos la estructura principal de nuestra página web. Ya se pueden visualizar el encabezado, el menú, la portada y las primeras categorías.

4. Conclusión del avance
En este 20% aprendimos a utilizar las etiquetas básicas de HTML5 y a dar estilos con CSS3. También practicamos cómo organizar una página web y adaptarla a diferentes tamaños de pantalla.
